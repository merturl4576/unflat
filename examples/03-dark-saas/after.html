Three views, one graph

Traces, evals and cost read from the same span tree, so a number you see in one view is the same number everywhere else.

Traces

Every call, tool use and retry as one tree. Open a span and read the exact prompt that produced it.

Evals

Run graded suites against real traffic, not fixtures. A regression arrives as a diff instead of a feeling.

Cost

Tokens and dollars per feature, per customer, per deploy. Set a budget and hear about it before you pass it.

Alerts

Latency, failure rate and cost per request, watched continuously. Route to Slack or a pager with a two-field rule.

Replay

Re-run any historic trace against a new prompt, model or temperature. Compare the two side by side before shipping.

Datasets

Turn interesting traces into a labelled set in one click. Every eval starts as something that actually happened.

How it works

Two lines of setup, then the same three questions every week: what happened, was it any good, what did it cost.

STEP 01

Instrument

One decorator on the function that talks to the model. No sampling, no sidecar, no proxy in front of your traffic.

STEP 02

Observe

Traces stream in within a second. Latency, tokens and spend group themselves by route, model and release.
