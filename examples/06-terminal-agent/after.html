Install

Ship the boring parts.

Solder is a coding agent that lives in your terminal. Give it the ticket. It reads the repo, runs your tests, and hands you a diff you can read before you merge.

$npm i -g solder
See what it does

Node 20 or newer. macOS, Linux and WSL. Nothing leaves your machine except the prompt and the files you approve.

It reads the repo before it writes a line.

Most agents guess and apologise. Solder runs what you already have, then proposes the smallest change that makes it pass.

Tests first

Before it answers, Solder runs your test command and reads the failures. It reports what it found, not what it assumed.

ran npm test in 4.2s ✗ auth › refresh token expires early expected 3600, got 60 — src/auth/session.ts:41

Diffs you can read

Every change arrives as a diff with a one-line reason per hunk. Approve a hunk, skip a hunk, or ask why.

src/auth/session.ts - ttl: 60, + ttl: 60 * 60, why refresh tokens are issued in seconds, not minutes

Stays in your terminal

No web IDE, no browser tab, no sync. It uses your shell, your editor and your git. Uninstall with one command.

$ solder fix "flaky auth test" $ solder explain src/auth/ $ solder review --staged

One command, three receipts.

You get a test run, a diff and a commit message. Nothing is applied until you say so.

  1. 01Readsthe files the failing test touches, the imports, and the last ten commits that changed them
  2. 02Runsyour test command, records the failures, and tries the smallest fix first
  3. 03Reportsa diff with one reason per hunk, the green test run, and a commit message you can edit
